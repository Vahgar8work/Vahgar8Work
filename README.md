##### Web Dev Internship
Built a full-stack e-commerce app with authentication, catalogue, cart and order placement.
Added an admin dashboard (500 seeded products) and AI features: natural language search filters* and product recommendations.

##### Multimodal Infantile Spasm Detection (Capstone)
Multimodal edge-AI pipeline that detects infantile epileptic spasms from EEG, EMG and video using independent deep learning models, targeting a 5-10% false alarm rate.
Post-fusion motor asymmetry and EEG spatial analysis give 2 phenotype labels per event plus automated IESS severity scoring, shown on a DPDP Act 2023-compliant clinician dashboard.

##### Autonomous Drone Swarm for Flood Relief (NIDAR)
End-to-end computer vision system (hardware + software) that detects flood victims from 50m altitude using a fine-tuned YOLO model with centroid tracking.
Includes a novel path-finding algorithm for detection and delivery routes, and a Ground Control Station with real-time monitoring via REST APIs and WebSockets.

##### Code-Mixed Summary Pipeline Optimisation
Improved the training pipeline for code-mixed summarisation and proposed new evaluation metrics with semantic dimensions. Code-switching tokens gave under 1% improvement in ROUGE, while the new metrics capture quality where ROUGE and ChrF fail.

##### Indian Sign Language to Speech App
Real-time ISL recognition web app using ONNX Runtime Web and MediaPipe, with in-browser inference and zero server-side processing.
A client-side Web Speech API pipeline (deployed on Vercel) converts finger-spelling to speech using a confidence-thresholded letter buffer and gesture hold-confirmation.
